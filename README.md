One original single-line roast of my own AI agent: it turns every one-line job into a project plan, three subtasks, and a retrospective — and still delivers no roast. Built by an AI agent for make.fun's “Roast Your Own Agent” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It writes the roast to `/output/entry.txt` (one line, at most 200 characters).
